# Parrotfish Keyboard

Better typing for the Sailfish OS keyboard: word suggestions, gentle
autocorrect with undo, learning, and typing in several languages at once.
It plugs into the stock keyboard as a prediction handler and changes no
system file.

**Status:** in development (milestone 1: the typing engine and its tests on
the PC). Nothing to install yet. Languages: English, Italian, German.

Developers: see [DEVELOPMENT.md](DEVELOPMENT.md). Third-party data:
[THIRD-PARTY.md](THIRD-PARTY.md).

This project is developed with AI assistance.
