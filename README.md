# Parrotfish Keyboard

Better typing for the Sailfish OS keyboard: word suggestions,
autocorrect with undo, learning, and typing in several languages at once.
It adds one layout to the stock keyboard, "Auto (Parrotfish)" (QWERTY,
QWERTZ, AZERTY or QWERTY with å ö ä, chosen in its settings), which picks
the typing language from what you write. Jolla's own layouts are left as they are, and no
system file is changed.

**Status:** in development (milestone 1: the typing engine and its tests on
the PC). Nothing to install yet. Languages: Danish, Dutch, English, Finnish,
French, German, Italian, Norwegian Bokmål, Portuguese (Brazil and Portugal),
Romanian, Spanish, Swedish; the settings choose which ones you type in.

Developers: see [DEVELOPMENT.md](DEVELOPMENT.md). Third-party data:
[THIRD-PARTY.md](THIRD-PARTY.md).

This project is developed with AI assistance.
